# BGP Labs

This section contains hands-on BGP labs completed using Cisco Modeling Labs (CML) as part of my CCNP ENCOR studies.

## Topics Covered

- eBGP Neighbor Establishment
- Classic BGP Configuration
- IPv4 Address-Family Configuration
- BGP Router ID
- BGP Route Origination
- BGP Path Attributes
- BGP Best-Path Selection
- BGP Troubleshooting

## Lab Documentation

Each lab will include:

- Network topology
- Router configurations
- Verification commands and output
- Screenshots demonstrating successful operation
- Troubleshooting scenarios
- Key takeaways
