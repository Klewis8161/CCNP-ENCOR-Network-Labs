# BGP Labs

This folder contains hands-on BGP labs completed using Cisco Modeling Labs (CML).

## Topics Covered

- eBGP Neighbor Establishment
- Classic BGP Configuration
- Address-Family Configuration
- BGP Router ID
- BGP Network Statements
- Route Origination and Redistribution
- BGP Path Attributes
- BGP Route Selection
- BGP Troubleshooting

Each completed lab includes configurations, verification output, topology screenshots, and an explanation of the results.
